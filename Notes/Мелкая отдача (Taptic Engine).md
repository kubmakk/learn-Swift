В iOS за тактильную отдачу отвечает фреймворк **UIFeedbackGenerator**. Если ты хочешь добавить разные типы вибрации (короткий отклик или длинный), тебе нужно использовать разные подклассы этого генератора.

------

## 1. Мелкая отдача (Taptic Engine)

Для легких касаний, как при нажатии на кнопку или переключении «тумблера», используется `UIImpactFeedbackGenerator`. У него есть параметр **style**, который определяет силу удара:

- `.light` — мягкий, едва заметный «тык».
- `.medium` — стандартный отклик.
- `.heavy` — сильный, отчетливый удар.

Swift

```
// Пример для легкого касания
let generator = UIImpactFeedbackGenerator(style: .light)
generator.prepare() // Подготавливает Taptic Engine (снижает задержку)
generator.impactOccurred()
```

## 2. Долгая или специфическая вибрация

Если под «долгой» ты имеешь в виду системное уведомление об ошибке или успехе, используется `UINotificationFeedbackGenerator`. Он проигрывает серию импульсов:

- `.success` — двойной быстрый отклик (как при оплате Apple Pay).
- `.warning` — прерывистый отклик.
- `.error` — серия из нескольких быстрых вибраций (длиннее по ощущению).

Swift

```
let generator = UINotificationFeedbackGenerator()
generator.notificationOccurred(.error) // Самый «длинный» и заметный из стандартных
```

## 3. Кастомная вибрация (Core Haptics)

Если стандартных пресетов мало и нужна действительно **долгая** или уникальная вибрация (как в играх), используется фреймворк **Core Haptics**. Он позволяет буквально «рисовать» паттерны вибрации, меняя их интенсивность и резкость во времени.

------

### Сводная таблица для выбора:

| **Тип отклика**   | **Класс**                         | **Стиль / Тип**      | **Ощущение**            |
| ----------------- | --------------------------------- | -------------------- | ----------------------- |
| **Мелкий (Soft)** | `UIImpactFeedbackGenerator`       | `.soft` или `.light` | Едва заметный щелчок    |
| **Средний**       | `UIImpactFeedbackGenerator`       | `.medium`            | Стандартная кнопка      |
| **Сильный**       | `UIImpactFeedbackGenerator`       | `.heavy`             | Плотный удар            |
| **Успех**         | `UINotificationFeedbackGenerator` | `.success`           | Радостный двойной «тык» |
| **Ошибка**        | `UINotificationFeedbackGenerator` | `.error`             | Тревожное дребезжание   |

**Важный совет:** Всегда вызывай `.prepare()` перед `.impactOccurred()`. Это заставляет Taptic Engine «проснуться» заранее, чтобы вибрация случилась ровно в момент касания, без микро-задержки.
