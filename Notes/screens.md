**все визуальные элементы (кнопки, поля, картинки, стеки) наследуются от базового класса `UIView`.** Это значит, что у них есть общий набор настроек (например, фон, рамка, прозрачность), к которому добавляются их уникальные фишки.

### 📦 1. Базовые свойства (Доступны вообще ВСЕМ объектам)

За эти вещи отвечает класс `UIView` и его слой отрисовки (`layer`). Это работает и для кнопок, и для полей, и для картинок.

| **Что меняем (Возможность)** | **Свойство / Метод в коде**                        | **Степень кастомизации**                                     |
| ---------------------------- | -------------------------------------------------- | ------------------------------------------------------------ |
| **Цвет фона**                | `backgroundColor`                                  | Любой цвет системы, кастомный HEX или паттерн.               |
| **Скругление углов**         | `layer.cornerRadius`                               | От 0 (квадрат) до половины высоты (идеальный круг/овал). *Важно: требует `clipsToBounds = true`, чтобы обрезать контент по форме.* |
| **Рамка (обводка)**          | `layer.borderWidth` и `layer.borderColor`          | Любая толщина и цвет. Цвет нужно переводить в формат `.cgColor`. |
| **Тень**                     | `layer.shadowColor`, `opacity`, `offset`, `radius` | Максимальная. Можно сделать мягкое свечение или жесткую тень с любым смещением (как в CSS). |
| **Прозрачность**             | `alpha`                                            | От **0.0** (полностью невидим, но кликабелен) до **1.0** (полностью виден). |
| **Скрытие объекта**          | `isHidden`                                         | `true` или `false`. Объект исчезает и перестает принимать нажатия (тот самый "плащ-невидимка"). |

### 📝 2. Поля ввода (`UITextField`)

Здесь всё крутится вокруг работы с текстом, клавиатурой и внутренними отступами.

| **Что меняем (Возможность)**         | **Свойство / Метод в коде**                 | **Степень кастомизации**                                     |
| ------------------------------------ | ------------------------------------------- | ------------------------------------------------------------ |
| **Подсказка (серый текст)**          | `placeholder` (или `attributedPlaceholder`) | Можно задать простой текст или полностью стилизованный (другой цвет, шрифт, межбуквенный интервал). |
| **Скрытие символов (для пароля)**    | `isSecureTextEntry`                         | Включает скрытие текста точками (`true`/`false`).            |
| **Тип клавиатуры**                   | `keyboardType`                              | Огромный выбор: `.emailAddress` (добавит @ на клавиатуру), `.numberPad` (только цифры), `.phonePad` и т.д. |
| **Кнопка "Return" (Готово)**         | `returnKeyType`                             | Меняет синюю кнопку на клавиатуре: `.done`, `.next`, `.search`, `.go` и т.д. |
| **Отступы и иконки внутри**          | `leftView`, `rightView` + `leftViewMode`    | Максимальная гибкость. Можно вставить просто пустую `UIView` для отступа текста (как у тебя в коде) или положить туда иконку лупы/глазика. |
| **Кнопка быстрой очистки (крестик)** | `clearButtonMode`                           | Можно настроить так, чтобы крестик появлялся, только когда юзер начал печатать (`.whileEditing`). |

### 🔘 3. Кнопки (`UIButton`)

Кнопки в iOS уникальны тем, что у них есть **состояния** (`.normal` - обычное, `.highlighted` - нажатое, `.disabled` - отключенная). Почти все настройки задаются с привязкой к состоянию.

| **Что меняем (Возможность)** | **Свойство / Метод в коде**                                  | **Степень кастомизации**                                     |
| ---------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Текст**                    | `setTitle("Текст", for: .normal)`                            | Можно сделать так, чтобы при нажатии текст менялся (например, с "Войти" на "Загрузка..."). |
| **Цвет текста**              | `setTitleColor(.white, for: .normal)`                        | Отдельный цвет для обычного состояния и, например, серый для неактивного. |
| **Картинка / Иконка**        | `setImage(UIImage(named: "icon"), for: .normal)`             | Можно поставить иконку слева от текста или вместо него.      |
| **Картинка на фон**          | `setBackgroundImage(..., for: .normal)`                      | Как у тебя в коде с пикселями. Позволяет кнопке менять цвет или текстуру фона прямо в момент касания. |
| **Действие по клику**        | `addTarget(self, action: #selector(твойМетод), for: .touchUpInside)` | `.touchUpInside` — стандартный клик (нажал и отпустил палец внутри кнопки). Можно ловить даже свайпы по кнопке. |

### 📚 4. Контейнеры и картинки (`UIStackView` и `UIImageView`)

**Для `UIStackView` (Стек):**

- **`axis`**: Направление (`.vertical` - в столбик, `.horizontal` - в строку).
- **`spacing`**: Расстояние между элементами внутри стека в поинтах (например, `stack.spacing = 16`).
- **`distribution`**: Как элементы делят между собой место (например, `.fillEqually` сделает все элементы одинакового размера, а `.fill` заставит их занять всё свободное пространство).

**Для `UIImageView` (Картинка):**

- **`image`**: Сама картинка.
- **`contentMode`**: Как картинка вписывается в рамки. `.scaleAspectFit` (вместить полностью, оставив пустые края) или `.scaleAspectFill` (заполнить весь квадрат, обрезав лишнее — *обязательно нужен `clipsToBounds = true`*).
